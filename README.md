# MPC-inspired Sampler Workstation

A sampler/sequencer workstation that visualises and emulates the workflow and sound character of four
classic and modern MPC families (MPC60/3000, MPC2000XL, MPC Live II/One+, MPC X/Key 61).

- **Test phases:** web app (React + TypeScript + Web Audio)
- **Release target:** native macOS app (JUCE 8 C++ engine + the same React UI in a WebView)

**Read [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md) first.** It holds the architecture, feature map,
the hard constraints (Spotify, trademarks, plug-in hosting), and the task list with the AI model
assigned to each task.
